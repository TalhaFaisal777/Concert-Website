# Concert Website

A single-page React website for a concert / music event, with navigation, an "Our story" section, products, pricing plans and an FAQ.

One of my early React projects, built to practise component structure, routing and responsive CSS.

## Tech stack

React · React Router · CSS (component-level stylesheets) · Create React App

## Run locally

```bash
npm install
npm start
```

## Structure

```
src/Components/   Navbar, Ourstory, Products, Pricing, Faq
```
